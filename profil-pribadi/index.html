Tentang saya

Belajar dari dasar Berkarya melalui kode

Saya adalah siswi Rekayasa Perangkat Lunak (RPL) yang memiliki ketertarikan pada pengembangan website. Saat ini, saya sedang menempuh sertifikasi Junior Web Developer sebagai bagian dari proses untuk mengembangkan dan menguji kemampuan saya dalam dunia web development.

Dalam prosesnya, saya mempelajari dasar-dasar pengembangan web, mulai dari HTML untuk membangun struktur halaman, CSS untuk mengatur tampilan, JavaScript untuk menambahkan interaksi, serta PHP dan PostgreSQL untuk mengembangkan fitur dinamis dan mengelola data.

Melalui dua proyek uji kompetensi, yaitu website profil pribadi dan toko daring Amoura Atelier, saya menerapkan kemampuan tersebut untuk membangun website yang tidak hanya menarik secara visual, tetapi juga memiliki fungsi dan pengelolaan data yang baik.
